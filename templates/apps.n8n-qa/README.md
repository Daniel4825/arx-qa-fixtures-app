# n8n - Workflow Automation Platform

n8n is a free and source-available fair-code licensed workflow automation tool. It allows you to easily automate tasks across different services with a visual workflow editor and AI capabilities.

## Features

- **Visual Workflow Editor**: Design complex workflows with an intuitive drag-and-drop interface
- **400+ Integrations**: Connect to popular services like Slack, GitHub, Google Sheets, and more
- **AI Integration**: Integrate with AI services like OpenAI, Anthropic, and more
- **Custom Code**: Write JavaScript or Python code for custom logic
- **Self-Hosted**: Full control over your data and workflows
- **API & Webhooks**: Trigger workflows via HTTP requests
- **Scheduled Executions**: Run workflows on a schedule with cron expressions

## Resource Requirements

- **CPU**: 1 core
- **Memory**: 2 GiB
- **Storage**: 10 GiB

## Configuration

After deployment, you need to configure the following:

1. Set up basic authentication credentials
2. Configure webhook URL for external triggers
3. (Optional) Connect to Redis for queue mode and horizontal scaling
4. (Optional) Configure AI service API keys for AI integrations

## Use Cases

- Data synchronization between services
- Automated notifications and alerts
- Document processing and generation
- AI-powered content creation
- API integrations and webhooks
- Database operations and ETL
